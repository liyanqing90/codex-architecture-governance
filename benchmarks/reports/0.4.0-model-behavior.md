# Version 0.4.0 model behavior evidence

Observed on 2026-07-29 with `codex-cli 0.146.0-alpha.3.1`.

## Method

- Ten outcome-neutral, read-only fixtures.
- Two identified models.
- Three fresh, ephemeral Codex processes per model and case.
- Sixty accepted trials in total.
- Ground truth was not included in prompts, fixture names, or fixture content.
- Finding IDs were constrained to machine Rule Packs.
- Paths, line ranges, and excerpts were resolved against fixture bytes.
- The adapter permitted at most one evidence-only correction and failed a trial
  if the corrected evidence was still invalid.
- Solution decisions used canonical option IDs and atomic trade-off IDs.

The complete structured trials and deterministic scores are preserved in:

- `benchmarks/results/gpt-5.6-terra.yaml`
- `benchmarks/results/gpt-5.6-terra-score.json`
- `benchmarks/results/gpt-5.6-sol.yaml`
- `benchmarks/results/gpt-5.6-sol-score.json`

## Interpretation

Both models avoided every fixture-specific forbidden recommendation and never
selected an over-designed target. Evidence validity reached 1.0 after bounded
validation, and every cited Knowledge ID existed in the catalog. Solution
selection, rejected-option explanations, and reversible migration slices were
strong, especially for `gpt-5.6-sol`.

The results do not establish universal architecture competence. The durable
approval case still produced consolidated or missed rule families across some
trials. One Terra project-audit trial selected a semantically related data
Rule ID instead of the project Rule ID. Sol sometimes emitted evidence-backed
`info` observations in the negative SQLite fixture even though the benchmark
task requested violations only. Both models cited valid knowledge but omitted
some expected case-study entries, leaving required-knowledge coverage at
0.708. Terra also varied one selected option ID and omitted some required
trade-offs.

These are retained as measured limitations rather than rewritten ground truth.
Scores are time-bound evidence for the named models, Codex surface, fixtures,
and plugin version only.
